# GlossaryConverter

A powerful tool for converting glossary and translation memory files between multiple formats:

- TMX ⇄ SDLTM ⇄ Excel
- TBX ⇄ CSV
- SDLTB ⇨ TBX / CSV

Built with **Python** and **Streamlit**, with selective use of **Java (Jackcess)** for SDLTB parsing.
